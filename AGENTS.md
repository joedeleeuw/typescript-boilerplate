# Repository agent instructions

This file is authored and owned by this repository. It is not generated by
Antidrift or synchronized from another project.

## Architecture

- [The web app](apps/web/src/App.tsx) owns browser interaction and the input draft.
  Derive the greeting directly; do not mirror it in React state or effects.
- [The domain package](packages/domain/src/index.ts) owns platform-independent
  behavior. It must not import apps, React, browser APIs, or Node APIs.
- Consume `@typescript-boilerplate/domain` through its declared public export.
  Never import sibling package source or add TypeScript source-path aliases to
  bypass package exports.
- Keep TypeScript strict. Each package owns its environment and project inputs;
  the root [base config](tsconfig.base.json) only extends shared tooling.
- Shared `@joedeleeuw/typescript-tooling` and `@joedeleeuw/antidrift` are independent
  dependencies. Compose their native configs here, never vendor their sources
  or make tooling import governance.

## Workflow and validation

- Use Node 24 and the pinned pnpm version. Preserve unrelated local work.
- Run `pnpm install --frozen-lockfile` after a fresh clone. Dependency changes
  must update the manifest and lockfile together.
- `pnpm dev` builds domain first, then starts Vite. Rebuild domain after changing
  it while the web dev server is running.
- Before handing off code, run `pnpm check`: formatting, build, typecheck, both
  lint engines, and architecture boundaries must pass.
- For web changes, exercise the real page: empty name, a typed name, clearing the
  input, keyboard focus, and a narrow viewport. A source check is not UI proof.
- Do not add placeholder tests, fixtures, no-op scripts, blanket rule disables,
  or type assertions to appease a failing check. Report exact failures and fix
  their owning contract.
- Do not commit generated `dist`, dependency folders, reports, credentials, or
  personal environment files. Do not publish or push unless explicitly asked.

## Scope

Keep this starter small. Add a backend, persistence, router, schema library, or
extra workspace only when an actual product requirement needs it. Do not add
Antidrift research machinery, policy generation, external agent sync blocks, or
private installed hook paths. Update this file and [CLAUDE.md](CLAUDE.md) directly
when durable repository guidance changes.
